# SyncTube 개인정보처리방침

최종 업데이트: 2026년 8월 14일

SyncTube는 여러 사용자가 같은 YouTube 동영상을 함께 볼 수 있도록 재생 상태를 동기화하는 Chrome 확장 프로그램입니다.

## 처리하는 정보와 목적

SyncTube는 서비스 제공을 위해 다음 정보를 처리합니다.

- YouTube 동영상 ID, 현재 재생 시간, 재생 또는 일시정지 상태: 방 참여자 간 영상 상태를 동기화하기 위해 사용합니다.
- 방 코드 및 호스트·참여자 역할: 방을 생성하고 참여자를 연결하기 위해 사용합니다.
- 연결을 유지하기 위한 임시 Socket.IO 연결 정보: 실시간 동기화 메시지를 전달하기 위해 사용합니다.

확장 프로그램은 방 코드, 역할 및 마지막 재생 상태를 사용자의 기기 내 Chrome 로컬 저장소에 저장합니다. 이 정보는 계정 생성, 광고, 분석 또는 프로파일링 목적으로 사용하지 않습니다.

## 보관 및 삭제

방 상태는 서버 메모리에만 임시로 보관됩니다. 호스트가 방을 나가면 즉시 삭제되며, 연결이 끊긴 경우에는 호스트 재연결을 위해 최대 30초 동안만 유지한 뒤 삭제됩니다.

서비스 운영 및 보안을 위해 웹 서버가 IP 주소, 요청 시각, 기술적 요청 정보를 일시적으로 로그에 기록할 수 있습니다. 이 로그는 광고, 판매 또는 사용자 행동 분석 목적으로 사용하지 않습니다.

## 제3자 제공

SyncTube는 이용자 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. YouTube 동영상은 YouTube에서 재생되며, YouTube의 이용 및 개인정보 처리에는 Google 및 YouTube의 정책이 적용됩니다.

## 원격 코드

확장 프로그램의 실행 코드는 Chrome Web Store에 업로드한 패키지에 포함됩니다. SyncTube 서버는 방 코드와 영상 동기화 상태만 교환하며, 원격 코드를 내려받거나 실행하지 않습니다.
